## 順 1、2 の設計

- C# は C 系の共通部(`src/lex/c-like.js`)を使う。逐語的文字列 `@"..."`、補間文字列 `$"..."`、生文字列 `"""..."""`、文字リテラル、`#region` などのプリプロセッサの行を字句解析のテストで確かめる。`///` は doc コメントとして扱う。
- TypeScript は JavaScript の字句解析を使えるかを、まずテストで確かめる。型の引数(`<T>`)の後の `/` と正規表現の判定、テンプレート文字列、`.tsx` の JSX を境界の例にする。使えなければ、差を足した言語のモジュールにする。
- どちらも、`lint` の規則のテストに、その言語のコメントの当たる例を 1 つ以上足す。
